Compatibility

This plugin targets IntelliJ IDEA 2025.1+ (since build 251).
Current development baseline is 2025.1.4.1, with compatibility updates for newer 2026.1 builds.

About

MBKarate For AutoTest is built for MB Bank automation teams using the Karate framework. It extends standard Gherkin/Cucumber support with navigation, documentation, validation, execution helpers, and project-level utilities.

Installation

  1. Install the plugin from your internal marketplace or from the plugin package.
  2. Ensure Gherkin and Cucumber for Java are installed/enabled.
  3. Restart IntelliJ IDEA.

Core Features

  1. Navigation (Go to Declaration)
    Navigate from call read('classpath:...'), src/... paths, and inline file references (for example data.json) to target files/scenarios.
  2. Missing Path Warnings
    Warns when referenced .feature, .json, or .txt paths cannot be resolved.
  3. Documentation Hover (DocView)
    For call read(...), reads scenario doc blocks and renders structured docs with: @short, @param, @return, @snippet_before, @snippet_after.
  4. Call Input Validation
    If docs define @param with {required}{input}, missing inputs in call read(...) are flagged.
  5. Autocomplete for Calls and Tags
    Trigger-based completion: # for file-oriented call suggestions, ! for scenario tag suggestions, & for @short suggestions.
    Required input params are auto-filled, including {DEFAULT:...} values when present.
  6. Variable Name Completion
    Variable suggestions are available in feature files and can be toggled via editor action Enable/Disable Variable Suggestion.
  7. Scenario Impact (Gutter + Graph)
    For scenario tags, shows where the scenario is reused via call statements. Popup includes direct usages and Investigate... to open the impact graph.
  8. Custom Test Execution
    Gutter action on tags to Run or Debug using generated TestRunner.java from configurable templates.
    Configure in Settings → Tools → Karate Test Runner.
  9. Jira Integration
    Jira issue tags (for example @MBA-12345) get gutter actions and intention actions to open issues quickly.
    Configure in Settings → Tools → Jira Integration.
  10. Import cURL as Karate Feature
    Editor popup action to paste cURL and convert it into Karate syntax. The current editor document is replaced with generated feature content.
  11. Document Helper
    Wizard-style helper to create/update scenario documentation blocks in feature files.
  12. Karate Tree Explorer (Tool Window)
    Browse feature/scenario hierarchy and navigate quickly across call relationships.
  13. Short Playbook (Tool Window)
    Central index of @short entries with search and jump-to-source.
  14. Examples Table GUI Editor
    Spreadsheet-style editor for Examples: tables (add/remove rows and columns, paste/edit values, sync back to feature file).

Settings

  • Tools → Jira Integration: Jira base URL and tag pattern.
  • Tools → Karate Test Runner: runner template, target file path, and execution behavior.
  • Tools → Variable Suggestion Patterns: variable extraction patterns/settings.
